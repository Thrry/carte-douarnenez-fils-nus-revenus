# Carte fils nus BT et revenus IRIS - Douarnenez

Carte interactive de lecture de la convention tripartite Douarnenez - SDEF - Enedis, croisée avec les revenus médians INSEE Filosofi 2021 par IRIS.

Source revenus : INSEE Filosofi 2021.
Source contours : IGN/INSEE Contours IRIS.

Les points d'opération sont des localisations approximatives issues de l'annexe PDF et d'OpenStreetMap. Ils ne constituent pas des tracés techniques opposables.
