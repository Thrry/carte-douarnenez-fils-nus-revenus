# Carte fils nus BT et revenus - Douarnenez

Carte interactive de lecture de la convention tripartite Douarnenez - SDEF - Enedis, croisée avec les données carroyées INSEE Filosofi 2021 à 200 m.

Source revenus : INSEE Filosofi 2021.
Source contours : IGN/INSEE Contours IRIS.

L'indicateur 200 m affiché est un niveau de vie moyen winsorisé estimé, et non une médiane. Les points d'opération sont des localisations approximatives issues de l'annexe PDF et d'OpenStreetMap. Ils ne constituent pas des tracés techniques opposables.
